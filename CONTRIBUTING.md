# Contributing

1. Fork the repository and create a focused branch (`feat/...` or `fix/...`).
2. Install dependencies with `npm install` and configure `backend/.env`.
3. Run `npm run dev`; run backend tests with `npm test -w backend`.
4. Add or update tests for behavior changes.
5. Open a pull request with motivation, screenshots for UI changes, and test results.

Please do not submit secrets, real student data, or unlicensed assets.
